## 카테고리

1. **프로필** — 전공, 연락처, 강점
2. **학력** — 간호학과 재학 및 보육복지과 졸업 이력
3. **실습·활동** — 어린이집·아동센터 현장 실습과 학습·탐구
4. **자격·수료** — 보육교사·사회복지사 자격 및 Coursera 수료증 링크
5. **자기소개** — 간호를 대하는 자세와 성장 목표

## Vercel 배포

이 저장소를 Vercel에서 가져온 뒤 Framework Preset을 `Other`로 선택하고 배포합니다. 별도 빌드 없이 루트의 `index.html`을 사용하며, 기존 `vercel.json` 설정을 유지합니다.
